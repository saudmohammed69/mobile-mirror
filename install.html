Replacing an older copy? Uninstall the previous version first. New builds use a different signature, and Android will refuse to install over the old one — it shows “App not installed” with no explanation.

Three steps

  1. Allow installs from your browser

    Tap the download, then on the prompt tap Settings and enable Allow from this source.

  2. Turn off the Play Protect scan

    Settings → Google → Play Protect → ⚙ → turn off Scan apps with Play Protect. This app is not on the Play Store, so it has no reputation score and gets flagged. You can turn the scan back on after installing.

  3. Install and open

    Tap the file again → Install. If a warning appears, choose More details → Install anyway. Then open the app and enable accessibility when it asks.

Problems

“Unsafe app blocked” with no Install anyway

That verdict is decided by Google, not by the phone. Turn off Scan apps with Play Protect — the block only applies while the scan is enabled.

“App not installed”

An older copy with a different signature is still installed. Uninstall it from Settings → Apps first, then install this one.

Install button greyed out

Either the APK is still downloading, or your Android is older than 8.0. Re-download on Wi-Fi and retry.

Chrome says “this type of file can harm your device”

That is Chrome's generic APK warning, shown for every download outside the Play Store. Tap Download anyway. It is not the Play Protect verdict.
